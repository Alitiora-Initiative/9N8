# 9N8 Polyglot Workspace

The Python + TypeScript control plane is supported by specialist native modules. They exchange authenticated requests, normalized UTC market data and immutable risk-approved intents. No adapter gets implicit access to the Solana wallet vault.

| Language | Module | Responsibility |
|---|---|---|
| Python | src/n9n8 | Telegram domain, Solana supervisor, quant/risk and orchestration |
| Rust | services/solana-core | Bounded signature dedupe and integer AMM math |
| C++20 | services/native-risk | Order-book spread, depth and impact calculations |
| Go | services/market-gateway | Authenticated OHLCV normalization service |
| TypeScript / JavaScript | supabase/functions, web | Telegram webhook, wallet verification and Mini App |
| SQL | migrations, supabase/migrations | Durable trade state, positions, receipts and worker jobs |
| Solidity | contracts/solidity | Optional EVM risk registry; not deployed |
| C# | platforms/metatrader-bridge | Broker quote, spread and exposure policy contract |
| MQL4 / MQL5 | platforms/metatrader4, platforms/metatrader5 | Signal-only terminal adapters |
| Pine Script | platforms/tradingview | Chart-side indicators and alerts |
| R | research/R | Statistical portfolio diagnostics |
| Julia | research/Julia | Seeded Monte Carlo experiments |
| Bash / Assembly | scripts and CI | Deployment/build automation; assembly listing generated by compiler |

## Network and execution boundary

The production Solana executor remains the only live signer. EVM contracts and broker adapters are isolated and cannot access the Solana wallet vault. MQL scripts publish signals only; they contain no broker order-placement calls. TradingView emits indicator alerts only. Every external signal must pass freshness, token-security, liquidity, risk and explicit-approval gates before becoming an execution intent.

## Running the modules

- Market gateway: set N9N8_GATEWAY_TOKEN and PORT, then run go run . in services/market-gateway. POST /v1/ohlcv/normalize requires bearer authorization; /healthz is a liveness probe.
- Native C++ risk: configure with CMake, build n9n8_orderbook_test, then run ctest. CI generates an assembly listing from this tested source.
- Rust core: run cargo test in services/solana-core.
- C# broker risk: run dotnet run --project platforms/metatrader-bridge/9N8.BrokerBridge.csproj.
- R diagnostics: set N8_SELF_TEST=1 and run Rscript research/R/portfolio_diagnostics.R.
- Julia Monte Carlo: run julia research/Julia/monte_carlo.jl.
- Solidity: compile with solc 0.8.26; deploy only after chain-specific audit and governance review.
- Pine/MQL: add scripts to the respective chart/terminal and configure the HTTPS signal endpoint. MQL WebRequest needs explicit terminal allow-list access.
