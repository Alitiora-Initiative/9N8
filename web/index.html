PRIVATE ACCOUNT CONNECTIONS

Connect your accounts.

Connect your own Binance Spot or OKX account for secure account reads, or link an EVM/Solana wallet. All connections are private to your Telegram account. 9N8's automated paper trading stays virtual; this connection page does not place real orders.

Exchange connection

Use a dedicated API key you create in your own exchange account. 9N8 validates private account access and encrypts the credential in Supabase Vault. It does not submit orders.

Use Binance Spot with read + Spot permissions only, or an OKX read-only key. Disable withdrawals, internal transfers, futures, margin and options. OKX read-only account access is supported; 9N8 does not execute trades from these keys. For complete key safety, restrict by IP where your exchange supports it.

Your exchange connections

Open this page from your Telegram private chat to load your connections.

Disconnecting here deletes the stored 9N8 Vault secret. It does not delete the API key at Binance or OKX; revoke that key in the exchange's security settings too.

Wallet sessions and address watch

Connect Phantom, Trust Wallet, MetaMask or another supported wallet through WalletConnect. The session is used for wallet identity and interactive signing requests; autonomous trading still needs a separate, explicitly granted permission.

Never enter a seed phrase, recovery phrase, private key, or wallet password. Only paste a public receiving address.
WALLET SESSION

Connect to a real wallet session. Desktop users can scan the WalletConnect QR in their wallet; mobile users can open their wallet app or use its deep link. 9N8 will request one harmless ownership message before saving the address.

Checking wallet connection settings…

The verification signature does not authorize a swap, transfer, token approval or trade. Wallet transaction approvals remain separate.
