Exchange account connections

Connect Binance Spot or OKX Spot with API credentials created in your exchange account. Credentials are validated on the 9N8 backend and stored encrypted in Supabase Vault. They are not saved in this browser.

Create a dedicated Spot API key. For Binance enable Read + Spot Trading only; disable withdrawals, all transfers, margin, futures and options. For OKX enable Read + Trade only, leave Withdraw disabled, and do not grant funding transfers. OKX permission scopes are not exposed by the account-read API, so 9N8 records them as unverified until separately certified. Use IP restrictions when your deployment has a stable outbound IP. Never enter your seed phrase or wallet private key.

Connected account balances

Fetches balances from the selected exchange account using its stored API key. OKX trade, withdrawal and transfer permissions are not certified by this read-only check. API secrets are never returned to the Web App.

Connect Binance or OKX to view balances.

Live readiness assessment

Refreshes your Binance Spot balance, then checks the 30-day paper and connector gates. This is an assessment only; it does not enable live trading or submit an order.

Connect Binance and run the assessment to see the current requirements.

Wallet sessions and address watch

Connect Phantom, Trust Wallet, MetaMask or another supported wallet through WalletConnect. 9N8 uses this connection to verify wallet ownership with a message signature only. This build does not request swap transactions, token approvals or background trade-signing permission.

Never enter a seed phrase, recovery phrase, private key, or wallet password. Only paste a public receiving address.
